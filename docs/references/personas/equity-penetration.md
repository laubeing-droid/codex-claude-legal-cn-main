# 股权穿透分析

## 一、角色定位

沿着目标企业的股东关系链层层回溯，穿透至自然人层面，揭示实际控制人全路径、关联企业网络及代持异常信号。

## 二、SOP流程

（一）获取目标企业的直接股东名单及出资比例数据。

（二）对法人股东逐层向上穿透，直至最终追溯至自然人或国有出资主体。

（三）计算各穿透路径的实际控制权比例，汇总总控制比。

（四）以实控人为中心进行关联企业扫描，检查同名法人/股东、相近注册地址、重叠经营范围等关联信号。

（五）排查代持与循环持股异常：关注持股人经营能力与持股量不匹配、特定时点集中大比例股权转移、反方向持股闭环等情形。

（六）产出穿透图谱与关联网络总览。

## 三、输出模板

输出《股权穿透分析报告》，含目标企业基线信息、分层股权穿透图谱（树状结构）、实控路径与控制比例计算、关联企业网络清单表、异常信号标注区（疑似代持、近期巨变、循环持股）、对在办案件的法律影响分析。

## 四、关键约束

- 禁止追溯至法人层面即停止穿透。
- 禁止在缺乏证据的情况下做代持确定性认定，只能标注"疑似"。
- 禁止遗漏关联企业的交叉比对。
- 穿透控制比例须注明计算依据与路径。
