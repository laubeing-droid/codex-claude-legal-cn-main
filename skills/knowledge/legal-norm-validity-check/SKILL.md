# 法律规范效力核验

## 一、三维核验框架

引用任何法律条文前须完成三个维度的交叉验证：

（一）时间效力：条文是否生效、是否被修订或废止。
（二）层级效力：制定机关是否具有相应立法权限、条文位阶是否正确。
（三）冲突检验：条文与上位法、同位法是否存在矛盾及如何选择适用。

## 二、效力状态等级

| 状态 | 标志 | 说明 |
|------|:----:|------|
| 现行有效 | ✅ | 已生效且未被修改废止 |
| 已有修订版 | 🔄 | 须引用修订后的新文本 |
| 部分失效 | ⚠️ | 整体有效但特定条款已被改动 |
| 已明示废止 | ❌ | 被新法明文废止，如《合同法》已被《民法典》第1260条废止 |
| 时效届满 | ❌ | 适用期限已过或调整对象消失 |
| 尚未施行 | ⏳ | 已公布但未到施行日 |
| 存疑待查 | ❓ | 无法确定，须进一步核实 |

## 三、操作步骤

### （一）规范身份锁定

确认法条的正式全称、制定机关、文号、公布日期、施行日期及引用的精确条款编号。重点识别同名异版（如《公司法》2018年修正版与2023年修订版）和"修正"与"修订"的差异——修正仅动个别条款，修订意味着全文新版本。

### （二）时间轴检索

沿时间轴逐一核查：
1. 施行日期是否已到达。
2. 是否设有有效期限且已届满。
3. 是否有修正/修订记录，引用条款是否在修正范围内。
4. 是否被明示废止（新法附则中的废止清单）或默示废止（新旧内容矛盾）。

### （三）立法权限核查

依据《立法法》核对制定主体的权限：
- 《立法法》第11条列举的法律保留事项（犯罪刑罚、人身自由限制、税收基本制度、非国有财产征收、诉讼制度等）只能由全国人大或其常委会立法。
- 部门规章依《立法法》第91条限于执行性立法，不得增设义务或减损权利。
- 设区的市地方性法规限于城乡建设、环境保护、历史文化保护等范围（《立法法》第80条）。
- 越权的规范即使形式上"发布"也不具被适用的正当性。

### （四）冲突排查

纵向冲突（上下位）：上位法优先（《立法法》第99条）。地方性法规与上位法冲突时不予适用。

横向冲突（同位法）：同一机关制定的规范，特别法优先于一般法，新法优先于旧法（《立法法》第103条）。新的一般规定与旧的特别规定冲突且无法确定的，由制定机关裁决。

跨类冲突：部门规章与地方性法规冲突，由国务院提出意见（《立法法》第104条）；部门规章之间冲突由国务院裁决（《立法法》第105条）。

### （五）特殊效力审查

1. 溯及力：法不溯及既往为原则，刑事领域从旧兼从轻（《刑法》第12条）。
2. 过渡条款：新法是否设置了过渡期，过渡期内旧法是否继续适用。
3. 地域效力：全国性法律在港澳的适用仅限于列入基本法附件三的清单。
4. 对人的效力：该规范是否仅适用于特定身份主体。

### （六）效力判定汇总

若时间效力层面已是❌（废止/失效/未施行），直接终止检查。其余情况汇总三维度结论给出最终判定，并标注置信度等级。

## 四、置信度分级

- 高（🟢）：权威数据库明确标注现行有效，无矛盾信号。
- 中（🟡）：近期有修正，引用条款未受影响但需核对；或存在冲突但有明确解决规则。
- 低（🔴）：无法确认最新状态、存在难以通过规则解决的冲突、或基于非权威来源。低置信度法条不得作为确定性结论的单据。

## 五、常见易错点

1. 《民法典》2021年1月1日施行同时废止了《民法通则》《合同法》《物权法》《担保法》《侵权责任法》等九部单行法，引用时须统一转换为《民法典》对应条款。
2. 法律修正后旧司法解释可能已不再适用，应查阅最高人民法院的司法解释清理决定。
3. 发布时间超过十年且未查到修正记录的地方性法规或部门规章，触发强制复核。
4. 规范性文件（红头文件）不属法律渊源，可作为裁判说理参照但不作为裁判依据。
5. 效力核验结论只代表检查时点的状态，法律环境具有动态性。
