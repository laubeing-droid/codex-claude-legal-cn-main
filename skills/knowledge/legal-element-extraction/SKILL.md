# 法律核心要素提取

## 一、三层事实过滤

案件叙述中的信息需穿透三个层次：

1. 原始叙述：口语化、情绪化、结构松散的日常叙事。
2. 法律相关事实：剔除情绪和评价后，与法律判断直接关联的事实单元。
3. 要件事实：可直接对应特定请求权或抗辩的构成要件的规范化事实。

例如："他一直拖着不还"（原始叙述）→ 借款金额5万元、约定还款期限1个月、逾期3个月未还、借款人删除出借人微信（法律相关事实）→ 借贷合意成立 + 履行期限届满 + 未返还借款（要件事实）。

## 二、九类事实单元

所有法律相关事实均可归入以下类型：

| 类型 | 核心问法 | 典型内容 |
|------|---------|---------|
| 主体事实 | 何人？ | 行为人、受害人、合同当事人、代理人、平台的身份及相互关系 |
| 行为事实 | 做了什么？ | 签约、支付、交付、通知、拒绝、转发、销毁等具体行为 |
| 时间事实 | 何时？ | 合同成立时点、履行期限、损害发生时点、知道或应当知道时点 |
| 地点事实 | 何地？ | 成立地、履行地、损害地、管辖连接点 |
| 对象事实 | 指向什么？ | 款项、货物、数据、作品、设备、人格利益等权利客体 |
| 结果事实 | 产生什么后果？ | 未履行、瑕疵交付、损害发生、隐私泄露、财产减损 |
| 因果关系事实 | 行为与结果的联系？ | 某行为是否导致某结果，是否存在介入因素中断因果链条 |
| 主观事实 | 主观状态？ | 明知/应知/未尽合理注意义务/善意/恶意/故意/过失 |
| 程序事实 | 采取了什么程序行动？ | 催告、协商、申诉、报案、起诉、通知、异议 |

## 三、事实属性四分法

同一叙述中的信息，需区分四种属性：

| 属性 | 特征 | 处理方式 |
|------|------|---------|
| 客观事实 | 可通过外部证据核验的具体行为、时间、地点 | 直接提取，标注证据来源 |
| 主观判断 | 当事人基于感受的推测，"我觉得、显然、肯定" | 剥离情绪词，追问背后的客观事实 |
| 法律评价 | 已带有规范归类或责任判定，"构成欺诈、属于违约、存在恶意" | 还原为支撑该评价的客观事实基础 |
| 背景信息 | 与法律判断无直接关联的叙事 | 剔除，仅保留辅助理解所需 |

核心原则：评价性表述不可直接作为分析前提，必须进一步还原为可被规范识别的客观事实。

## 四、操作步骤

### （一）切分最小事实单元

将复合叙事按句子拆分。每个事实单元应包含：主体 + 行为 + 时间 + 对象 + 结果，要素缺失的标注"待补充"。

### （二）类型化归类

将切分后的事实单元逐一归入九类事实类型，按类输出结构化清单。

### （三）属性辨析与净化

将具有主观判断或法律评价属性的单元，还原为客观事实。剔除纯背景信息。

### （四）生活语言→法律语言转化

使用中性、客观的规范用语转写净化后的事实：

| 生活语言 | 法律语言转化 |
|----------|------------|
| 他一直拖着不还 | 债务履行期限届满后债务人未履行 |
| 卖家明明说是新的 | 出卖人曾就标的物品质作出"全新"的表示 |
| 每次问他都说再等等 | 债权人多次催告，债务人屡次承诺履行但未实际履行 |
| 他删掉了我微信 | 债务人以删除通讯工具的方式单方面断绝联系 |

### （五）要件映射

识别可能的法律关系类型（合同、侵权、不当得利等），列出该关系的构成要件，将已提取的事实逐项对应至各要件。标注已满足、部分满足、缺乏事实三种状态。

## 五、输出形式

（1）结构化要素清单——按九类事实分类列出全部法律相关事实，标注证据来源和争议状态。

（2）要件映射表——列明法律关系、请求权基础，逐项对应各要件的事实支撑及满足状态。

（3）法律实践时间轴——按时间顺序排列重要行为、事件与法律节点，适用于复杂案件。

## 六、常见偏差防范

- 将评价当事实：遇到"构成欺诈"等表述时追问"什么具体行为使你得出这个结论"。
- 遗漏关键时间节点：对每项行为标注时间，不确定的标注"待确认"。
- 混淆不同主体行为：每个事实单元须明确标注行为主体。
- 遗忘程序事实：特别关注"有无催告、通知、提出异议、申请仲裁"。
