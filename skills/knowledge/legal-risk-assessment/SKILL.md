# 企业监管风险排查

## 一、能力定位

本能力面向企业外部监管风险的前置筛查，不替代专业法律尽调。结论依赖用户输入信息的完整性和真实性。

## 二、审查维度

### （一）经营资质审查

审查方法：
1. 获取企业经营范围说明和业务活动清单。
2. 依据业务类型对照行业法规确定应持资质目录。
3. 逐项核查许可、备案、认证的持有状态、有效期和年检情况。
4. 排查超范围经营、许可过期未续、实际经营与核准不一致等问题。
5. 分类输出资质缺口及补办指引。

常见资质类别：
- 特种行业许可（如《食品安全法》第35条的食品经营许可）；
- 行业备案（如海关进出口收发货人备案，《海关法》第11条）；
- 增值电信许可（如经营性网站ICP许可证，《互联网信息服务管理办法》第7条）；
- 从业资格或资质证书。

### （二）监管合规审查

审查方法：
1. 识别企业主要业务线（安全生产、环保排放、产品质量、税务、劳动用工等）。
2. 逐线梳理核心监管法规及其强制性要求。
3. 以文件审核、访谈或现场核查方式比对企业实际状况与法规要求的差距，将结果整理为可调阅的文档。
4. 对不合规事项逐项标出对应的处罚条款和可能处罚幅度。
5. 输出合规缺口与整改优先级。

### （三）历史处罚与信用审查

审查方法：
1. 调取国家企业信用信息公示系统的行政处罚记录。
2. 核查企业是否列入经营异常名录、严重失信名单、失信被执行人等。
3. 评估现有记录对招投标资格、融资授信、政策申报的实际制约程度。
4. 对可修复的失信记录，参照《市场监督管理信用修复管理办法》第五条至第七条评估修复条件：

- 经营异常修复：补报年报并公示，或履行即时信息公示义务，或更正不实公示信息。
- 一般处罚修复：履行处罚义务、消除危害后果，公示满六个月（食药特设领域满一年），且未再犯同类违法、未被列入严违名单。
- 严违名单移出：列入满一年，履行义务且消除危害，未再受较重处罚。
5. 输出信用风险清单及修复应对方案。

## 三、输出要素

各项审查按"应持/应合规状态 → 实际状态 → 问题描述 → 规范依据 → 可能后果 → 整改路线"的结构逐条输出。信用审查额外附上"可修复性评估"和"修复路径"。

## 四、法源索引

- 资质类：《行政许可法》《食品安全法》《海关法》《互联网信息服务管理办法》及各行业许可规定。
- 合规类：《安全生产法》《大气污染防治法》《产品质量法》《劳动合同法》《个人信息保护法》《数据安全法》等。
- 信用类：《企业信息公示暂行条例》《市场监督管理信用修复管理办法》《最高人民法院关于公布失信被执行人名单信息的若干规定》。

## 五、使用说明

1. 监管政策处于变动之中，审查结论有时效性约束，须定期复核。
2. 用户未提供的信息领域可能导致风险遗漏，须在输出中标注信息缺口。
3. 外部数据库（企业信用信息公示系统等）可能需要账号访问，提请用户配合提供。
4. 本筛查系风险初判，涉及重大处罚风险应转介专业律师深入分析。
