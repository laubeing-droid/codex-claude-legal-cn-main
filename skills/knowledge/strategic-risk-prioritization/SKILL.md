# 法律风险优先级排序

## 一、框架原理

风险优先级 = f(发生概率, 影响程度, 时间紧迫度, 可控程度)

法律领域的概率评估区别于统计概率：它更多基于规范推理而非频率计数，受法官裁量空间和信息不对称影响。因此各项评级须附带置信度标注。

## 二、概率评级

### （一）五级标准

| 等级 | 标签 | 对应可能性 | 法律场景示例 |
|------|------|:--------:|-------------|
| P5 | 几近确定 | ≥85% | 法条明确、事实清楚、几乎无可争空间 |
| P4 | 高度可能 | 60%-85% | 主流观点支持但存在少数不同裁判 |
| P3 | 中等可能 | 40%-60% | 规范模糊、各地裁判分歧、结果不确定 |
| P2 | 概率较低 | 15%-40% | 少数观点，但不可完全排除 |
| P1 | 极低概率 | <15% | 法律明确排除或缺乏事实基础 |

### （二）评估考量因素

逐风险点考量：规范明确度、事实证据充分性、管辖法院裁判倾向、对方行为预判、政策环境变化趋势。

## 三、影响评级

### （一）五级标准

| 等级 | 标签 | 法律后果参考 |
|------|------|-------------|
| I5 | 灾难性 | 吊销核心资质 / 刑事责任 / 强制清算 / 交易失败 |
| I4 | 重大 | 重罚 / 业务限制 / 高额赔偿 / 重大声誉损失 |
| I3 | 中等 | 一般处罚 / 部分赔偿 / 合同变更 / 可承受的财务影响 |
| I2 | 轻微 | 警告 / 限期整改 / 小额赔偿 |
| I1 | 可忽略 | 几乎无实质损失 |

### （二）多维评估

影响需按六个方面加权汇总：直接经济损失（建议权重30%）、间接损失（20%）、法律资格影响（20%）、声誉损害（15%）、战略目标受损（10%）、连锁效应（5%）。权重可根据企业自身关切调整。

## 四、综合排序

### （一）基础风险值

基础值 = 概率评级 × 影响评级。乘积落入 20-25 为极高、12-19 为高、6-11 为中、3-5 为低、1-2 为极低。

### （二）调整因子

1. 时间紧迫性：即时风险（一月内）系数1.5，短期1.2，中期1.0，远期0.8。
2. 可控程度：完全不可控系数1.3，部分可控1.0，高度可控0.7。
3. 不可逆程度：完全不可逆系数1.3，高度可逆0.8。

调整后值 = 基础值 × T × C × R。

### （三）排序规则

调整值相等的风险，按影响更高、时间更紧迫、不可逆性更强的优先排列。标注风险之间的关联：风险A触发是否会导致风险B的概率显著上升。

## 五、验证与输出

### （一）排序校验

- 直觉检验：排序是否与经验判断大体一致，重大偏差须回溯审查。
- 同质校验：性质相同的风险，概率差异超过两级的须说明原因。
- 数量控制：极高优先级不超过总数的20%。
- 敏感性检测：若某项关键假设变化，排序是否剧烈变动，标记那些排序易受波动影响的敏感风险。

### （二）输出结构

报告应包含：排序总表（按调整值降级排列）、概率影响矩阵图（横轴概率五级、纵轴影响五级标注各风险位置）、关键发现摘要与应对策略建议、整体置信度与主要不确定性说明。

### （三）单项风险卡

对排名靠前的风险逐项制作详细卡：风险描述与法律依据、概率评估及依据（附置信度）、多维影响展开、调整因子数值及理由、初步应对策略与建议负责人。

## 六、特殊场景

1. 信息严重不足：取保守评级，输出条件性排序，将"补充信息"列为首要行动。
2. 风险强关联链：绘制触发链图谱，根源风险提级处理。
3. 当事人风险偏好极端：同时提供标准排序和偏好调整版本，但致命风险始终最高优先级。
4. 跨法域排序：先各法域独立评估再统一标准，增加"跨域执行可行性"因子。

## 七、常见偏误

- 遗漏关键风险：采用多方审查消除盲区。
- 概率与影响混同：将"后果严重"误判为"可能性高"。
- 过度量化幻觉：排序是方向性指引而非精确预测。
- 静态评估：设定复查节点，关键事件触发即时更新。
- 全部标"高"：失去排序意义，须强制分层。

## 八、适用范围

适用于诉讼策略、并购尽调、合规整改、合同审查等所有需在多个法律风险中做取舍的场景。排序结论系辅助决策参考，不代替最终法律判断。
