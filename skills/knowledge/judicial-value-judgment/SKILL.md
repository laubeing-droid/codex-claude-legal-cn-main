# 司法价值判断

## 一、调用前提

（一）并非每起案件都需调用本能力。先判断以下触发条件：
1. 法律规则本身存在模糊、开放或空白之处；
2. 个案中存在权利、利益或价值层面的实质冲突；
3. 存在多个合法方案，需在方案之间作出更优选择；
4. 机械适用规则可能导致显失公平或说理不足。

（二）应区分事实认定问题、规范解释问题、价值衡量问题与裁量选择问题。本能力聚焦后两类，前两类未解决时不得直接跳到价值结论。

## 二、框架步骤

### （一）锁定裁量问题

从案情中提炼出法官真正需要裁量的具体命题。使用"是否应……"或"应如何……"句式表述。

### （二）识别价值冲突结构

区分三种冲突形态：
1. 私人之间：一方自由行使权利与另一方人格、财产、隐私等权益的碰撞。
2. 共同体之间：不同公共利益或制度目标之间的张力。
3. 个人与公共之间：个体自由或财产权与公共秩序、行政管理的角力。

需明确冲突主体、具体价值、表现形式，以及是否为真实冲突（非可通过解释化解的表面冲突）。

### （三）定位相关法律价值

从以下核心类别中选择并具体化：
1. 秩序：社会关系稳定与权力运行有序，如《治安管理处罚法》保护的社会管理秩序。
2. 自由：主体依法自主行动，如《民法典》中的意思自治原则。
3. 平等：排除差别对待与特殊化特权，如《宪法》第33条的平等权保障。
4. 人的尊严：基本权利保护，如《宪法》第38条人格尊严条款。
5. 正义：利益、负担与责任的正当分配。
6. 效率：合理制度促进资源配置。

每项价值须说明其在本案的具体载体、事实支撑、受限制程度。

### （四）确认规范基础与裁量边界

检查是否存在明确的规则依据、原则指引、指导案例或司法解释。标注不可突破的下限——例如基本权利的核心保护领域、法定程序底线、权限边界。规范基础不足时应标注审慎说明。

### （五）适用价值位阶

位阶较高的价值在冲突中获得更大的论证权重。基本权利通常优先于非基本权利；人的尊严在裁判说理中具有较高权重。但不得以抽象位阶替代个案分析，仍须说明限制其他价值的必要性与限度。

### （六）个案平衡

同一位阶或难以排序的价值冲突，应综合考量：主体身份、行为方式、主观状态、各方受影响程度、是否存在替代安排、裁量结果对同类案件的外溢效应。个案平衡是在事实与规范基础上寻求兼顾方案，而非简单折中。

### （七）比例原则审查

当以保护某价值为由限制另一价值时，适用《行政处罚法》第5条过罚相当原则所体现的比例审查思维：
1. 目的正当：限制所欲实现的目标是否合法且重要。
2. 手段适当：所用措施能否有效促进该目标。
3. 必要性：有无损害更小的同等有效替代方案。
4. 均衡性：获得的公共利益是否明显超过被牺牲的个体利益。

### （八）重大案件中的根本利益考量

仅适用于疑难重大案件。须说明该利益对应的具体社会群体与制度目标，不得以笼统的抽象利益压倒个人基本权利，应作为补充性考量而非替代规则。

### （九）裁量方案比较

至少呈现两个方案，分别说明：支持价值、牺牲价值、规范基础、事实依托、优势、风险、是否符合前述原则。不宜仅展示单一方案。

### （十）说理框架输出

形成可供法官改写的说理段落，涵盖：为什么需要价值判断、冲突的具体结构、选择特定路径的理由、被限制价值是否获得最低保护、结论如何契合规范目的和正义要求。

## 三、边界声明

本能力不替代法官作出裁判；不处理纯事实争议或简单规则适用案件；不得编造规范依据或裁判结论；不能突破现行法律框架进行任意裁量；输出为裁判说理辅助材料而非正式文书。
