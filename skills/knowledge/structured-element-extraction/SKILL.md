# 结构化要素提取

## 一、要素的四项属性

每个要素应满足以下特征：

1. 原子性——不可再有意义地进一步拆分。
2. 可判断性——可以对其作出"满足/不满足/待查"的明确结论。
3. 独立性——同级要素之间逻辑上互不包含（MECE原则：相互独立、完全穷尽）。
4. 可追溯性——每个要素可溯源至具体法条或学理依据。

## 二、要素的三种来源

| 来源 | 说明 | 示例 |
|------|------|------|
| 法定要素 | 法条明确规定的构成要件 | 《民法典》第1165条侵权四要件 |
| 司法解释要素 | 司法解释对法定要素的细化 | 最高法对"经营场所"的认定标准 |
| 学理/实务要素 | 通说学理或裁判实务形成的判断维度 | 合同"实质性变更"的判断因素 |

## 三、要素状态标注

每个要素须标注以下状态之一：

| 标记 | 含义 |
|------|------|
| ✅ | 现有材料可充分证明该要素成立 |
| ❌ | 现有材料明确表明该要素不成立 |
| ⚠️ | 现有材料不足以判断，需补充信息 |
| ➖ | 在本案情形下不适用 |
| 🔶 | 满足与否存在不同解释空间 |

## 四、操作步骤

### （一）问题类型识别与框架选择

先识别法律问题的类型——合同纠纷、侵权责任、犯罪构成、行政行为合法性、程序事项等。然后调取对应标准要素框架：

| 问题类型 | 一级要素框架 | 核心法源 |
|----------|------------|---------|
| 一般侵权 | 加害行为、损害结果、因果关系、主观过错 | 《民法典》第1165条 |
| 合同纠纷 | 主体适格、意思表示真实、内容合法、合同成立、履行、违约 | 《民法典》第143条等 |
| 犯罪构成 | 客体、客观方面、主体、主观方面 | 《刑法》相关条文 |
| 行政合法性 | 职权依据、事实认定、法律适用、程序合法、裁量合理 | 《行政诉讼法》第70条 |
| 劳动争议 | 劳动关系成立、用工事实、书面合同、报酬、解除/终止 | 《劳动合同法》相关条文 |

### （二）逐项提取与填充

对照要素框架，从原始材料中逐一提取对应事实。每个要素独立提取、不可跳过。无法提取的要素标注为⚠️。为每个已满足的要素标注事实来源。

### （三）三重完整性校验

1. 框架完整性：是否遗漏标准框架中的任何一级要素？将提取结果与标准框架逐项比对。

2. 事实覆盖度：原始材料中是否有尚未被任何要素消化的重要事实？重新通读原始材料。

3. 逻辑自洽性：各要素之间是否存在逻辑矛盾？如因果关系要素与损害结果要素是否一致。

### （四）要素优先级筛选

| 层级 | 处理策略 |
|------|---------|
| 必要要素（Must） | 法定构成要件，缺一不可——必须列出，即使标为⚠️ |
| 重要要素（Should） | 影响法律效果轻重的因素——应当列出 |
| 参考要素（May） | 辅助价值但非必需——可以列出 |
| 排除要素（Exclude） | 与本案无关——不列出，简要记录排除理由 |

## 五、特殊场景

### （一）多法律关系交叉

为每个法律关系分别建立独立要素清单，标注共享事实要素的交叉引用关系。如存在请求权竞合，在备注中说明竞合关系。

### （二）法律规定模糊或空白

要素法源标注为"学理通说"或"类案裁判规则"，列出可参考的类案或学术观点。该要素置信度标注为中或低。

### （三）信息严重不足

仍然列出完整要素框架，将无法判断的要素全部标注⚠️，生成"信息补充请求清单"，按优先级排列。整体置信度标注为低。

## 六、置信度与行动决策

| 整体置信度 | 判断基准 | 允许行动 |
|-----------|---------|---------|
| 高 | 全部一级要素为✅或❌，无⚠️，三重校验通过 | 直接进入下一阶段 |
| 中 | 存在1-2个⚠️或🔶，但不影响核心判断 | 可进入但标注不确定点 |
| 低 | 存在3个以上⚠️或核心要素为⚠️ | 不得进入下一阶段 |

## 七、常见偏差

- 以结论替代要素——写成"构成侵权"而不拆分为四要件。必须拆分到独立要素层级。
- 遗漏消极要素——只关注成立要件，忽略免责事由和抗辩理由。
- 混淆事实与法律评价——在事实栏写入法律结论。
- 框架僵化——对所有案件套用同一要素框架而不根据具体法律问题类型调整。
- 忽略时间维度——未考虑法律修订导致的要素版本差异。
