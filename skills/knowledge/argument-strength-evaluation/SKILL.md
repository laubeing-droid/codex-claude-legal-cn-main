# 法律论证强度评估

## 一、评估框架

### （一）六维评价模型

论证强度从六个层面分别计分，加权汇总得出综合评定。

| 评价面向 | 核心考察内容 | 权重（常规案件） |
|----------|-------------|:---:|
| 规范依据明确度 | 所引法条是否现行有效、效力层级、是否存在解释分歧 | 0.25 |
| 事实基础充实度 | 关键事实的证据支撑程度、证据链完整性与举证责任分布 | 0.25 |
| 推理链条严密性 | 前提能否推出结论，有无逻辑跳跃、循环论证或偷换概念 | 0.20 |
| 反驳抵御能力 | 是否预判并有效回应对方最有力的反对论点 | 0.15 |
| 裁判实践契合度 | 与主流裁判倾向的一致性、指导案例的支撑程度 | 0.10 |
| 价值判断妥当性 | 利益衡量是否合理、是否符合立法目的与公序良俗 | 0.05 |

疑难案件或事实争议型案件可调整各维度权重，法律空白场景应将第一项上限压至3分。

### （二）薄弱节点分类

| 等级 | 标识 | 含义 |
|------|:----:|------|
| 致命缺陷 | ★5 | 足以推翻整体论证的根本问题（如援引《合同法》第107条而该法已被《民法典》废止） |
| 重大弱点 | ★4 | 显著削弱说服力的缺陷，关键要件缺乏直接证据 |
| 中度风险 | ★3 | 可能被他方利用的不确定性，如类案不统一 |
| 浅层瑕疵 | ★2 | 不影响核心结论的表述或论证顺序问题 |
| 潜在隐患 | ★1 | 目前不构成问题，但法律修订后可能暴露 |

## 二、操作流程

### （一）论证解构

1. 提取最终结论，明确待证明的命题。
2. 分离各项前提：区分事实前提、规范前提与隐含预设。
3. 识别使用的推理方式：演绎三段论、类比、目的解释等。
4. 将论证链条中的节点标注为事实节点[F]、规范节点[L]、推理节点[R]、预设节点[A]、价值节点[V]。

### （二）逐维评分

各维度按五级评定。以规范依据明确度为例：
- 5分：依据明确、位阶高、无争议，如《民法典》第577条对违约责任的一般规定。
- 3分：依据存在但有解释争议，如《个人信息保护法》中某些概念的边界。
- 1分：缺乏直接依据，依赖类推或抽象原则。

事实基础充实度维度，在刑事领域应执行更严格标准，因《刑事诉讼法》确立的证明标准为"排除合理怀疑"。

### （三）综合评定

综合评分 = Σ(维度评分 × 权重)。强度分档：≥4.5为极强、3.5-4.4为强、2.5-3.4为中等、1.5-2.4为弱、<1.5为极弱。

否决机制：规范依据或事实基础任一项为1分时，整体评级不高于"弱"。两项及以上维度≤2分时，整体不高于"中等"。

### （四）元评估

对评估行为本身进行反思性审查：自身是否充分掌握该领域法律知识，是否存在确认偏差，信息缺口是否显著影响结论。元置信度分为高/中/低三档，低置信度时应附加"评估可靠性有限"标注。

## 三、输出要素

评估报告应包含：论证概要、结构图示、各维度评分与理由、综合等级及元置信度、薄弱节点清单（含位置、类型、影响范围、修复建议）、总体改进方向。

## 四、注意事项

1. 论证强度系连续光谱，而非二元判断。
2. 须将论证内容与表述风格分离，避免因言辞自信给予虚高评级。
3. 常见偏误：确认偏误（倾向于验证既有结论）、锚定效应（受首次评估结果牵制）、权威崇拜（因引用权威而放松审查）。
4. 刑事案件的论证强度评估应执行更严格的降级规则。
5. 本评估属于辅助分析工具，最终判断应由执业法律人士作出。
