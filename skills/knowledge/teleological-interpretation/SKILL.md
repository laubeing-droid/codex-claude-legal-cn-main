# 目的解释

## 一、基本原理

目的解释的出发点是：法律条文的含义不仅由其文字承载，更由其规范目的所界定。当文义解释完成但无法在多个可能含义之间唯一选择时，目的解释介入——它追问"该条文意图解决的问题是什么"，据此指引含义的选择方向。

目的解释区分两个层面的"目的"：

（一）**主观目的**：立法者在制定条文时的实际意图。可从法条措辞结构、立法说明（草案说明、审议报告、修订说明）、立法背景及条文所要回应的原有制度缺陷等来源加以还原。

（二）**客观目的**：法律条款在当前法律体系和现实语境下应当承载的合理追求。分析维度包括：该条文在制度整体中的功能定位（一般规则还是例外条款）；所涉及的法律基本原则与价值取向；社会现实变迁产生的新需求；权威性判例中的目的表述。

## 二、操作流程

### （一）目的解释启动条件

前提：文义解释已完成但存在以下情形之一：
- 条文存在两种以上合理文义，无法择一；
- 文义解释结论导致明显不合理的结果；
- 条文包含开放式评价概念（如"合理""必要""重大""正当"），文义无法充分划界；
- 条文制定已久，面对新型事实时文义基础动摇。

### （二）主观目的探寻

按以下优先级获取资料：法条本身的用语与结构安排（最直接）→立法说明材料（草案说明、审议报告）→立法背景（当时力图解决的现实问题及旧规则不足）。

将主观目的提炼为一句完整的实质性陈述："该条通过[规制手段]，旨在达成[具体效果]"——避免泛化为"保护权益""维护秩序"等空洞口号。

立法材料缺失或模糊时，如实记录为"主观目的不明确"，并在后述整合中降低主观目的的权重。

### （三）客观目的建构

从四个维度展开：
1. **制度整体定位**：该条是一般规则还是例外、特殊规则？在本编/本章/本节中承担什么职能？
2. **基本原则与法律价值导向**：关涉平等保护、诚实信用、交易安全、人身安全、人格尊严等何种价值？
3. **社会现实需求**：新技术、新商业模式、新风险路径是否改变了条文应承载的合理期待？
4. **裁判实践参考**：相关指导性案例及权威判例中所阐明的目的取向。

同样提炼为一句实质性目的陈述。

### （四）主客观目的整合

根据一致性状态处理：
- **一致**：双重印证，依此导出解释结论，说服力最强。
- **主观目的不明**：以客观目的为主导。
- **冲突**：按三项标准分配权重——法规的新旧程度（越新主观目的权重越大）；条文的具体/抽象程度（越具体越重主观）；规则/原则属性（规则条款重主观，原则条款重客观）。

### （五）目的到含义的转化

目的本身不是答案，须转化至可操作的具体判断：该概念应作宽释还是窄释？本案事实应纳入还是排除该规则的适用范围？该例外条款应严格解释还是扩张解释？

## 三、合法性复核

结论在输出前须通过四项检验：

1. **文义底线**：结论仍在文字可能语义范围之内。
2. **体系相容性**：不会使相邻条文失去独立意义。
3. **上位法原则**：不违反宪法原则和基本法律价值。
4. **公开说服力**：论证能够经受公共理性的公开审视。

任一检验未通过，则返回目的整合阶段重新权衡。

## 四、适用边界

- 目的解释须以文义解释为前置步骤，不得跳过文义直接使用。
- 结论不得逾越条文的文字射程——超出的部分属于法律续造而非解释。
- "公平""正义"等价值话语须锚定在具体条文和制度功能上，不能脱离文本空谈。
- 目的解释区别于漏洞填补；当条文完全无法覆盖待决事实时，应转用类推适用或其他方法论工具。
