# 行政机关价值判断与裁量分析

## 一、分析流程

### （一）案情预处理

提取四项基础信息形成分析底稿：
1. 核心裁量问题——以"应如何处理""应否批准"等句式表述。
2. 受影响主体及各自处境。
3. 主要利益与价值清单，区分公共利益、个体权益、制度价值与工具价值。
4. 初步价值冲突定位。

### （二）合法性审查

参照《行政处罚法》《行政许可法》及相关行业法，检查拟议方案是否存在违法、越权、无依据的问题。明显违法的方案不得进入利益衡量。案情未提供关键合法性信息时必须标注。

### （三）合理性审查

排查《全面推进依法行政实施纲要》所要求的公平公正原则落实情况：
1. 是否存在"一刀切"式机械处理。
2. 是否出现显失公平结果。
3. 是否忽视个案特殊情境。
4. 是否将行政便利或考核压力包装为公共利益。

### （四）比例原则审查

依次审查三个子原则：
1. 适当性：手段是否有助于达成行政目的。
2. 必要性：是否存在对相对人权益损害更小的同效替代方案。有温和替代方案时原则上应优先选择。
3. 均衡性：行政管理所获公共利益增益是否显著大于个体权益减损。

参考《行政强制法》第5条的比例原则表述。

### （五）平等原则审查

同类情形是否同等处理，不同情形是否合理差异化。防止选择性执法。对弱势群体可作合理照顾，但需有规范依据支撑。

### （六）程序正当审查

梳理程序价值需求：
1. 是否需要告知理由与法律依据。
2. 是否需要听取陈述申辩。
3. 是否需要听证、论证或公开征求意见。
4. 重大权益受影响时应提高程序保障程度。

参照《行政处罚法》第62条至第66条的程序要求。

### （七）信赖保护审查

行政机关在先行为是否使相对人产生合理信赖，相对人是否基于信赖投入成本或形成稳定利益。若决定与先前行为不一致，应评估是否需要过渡期、整改缓冲、补偿或理由说明。参照《行政许可法》第8条的信赖保护规定。

### （八）利益衡量

1. 公共利益须落实到具体群体、具体受益方式。
2. 行政效率与管理便利属工具价值，通常位阶低于基础权利保障。
3. 个体权益可依法让位，但必须有充足说理且保留最低限度保护。
4. 比较各方案的利益接受面与权益牺牲面。

### （九）裁量结论

输出倾向性意见，须包含：
1. 推荐处理方向及核心理由。
2. 最小损害或缓冲安排。
3. 不宜采取的方案及排除原因。
4. 需进一步核查的事项（如违法严重程度、历史处理尺度、整改可行性）。

## 二、输出结构

输出固定格式的《行政机关价值判断与裁量分析》，从案前预处理到裁量结论共九节，逐节点呈现审查结论与理由。每一步均先做原则审查再做利益衡量。

## 三、注意事项

1. 本能力输出为倾向性内部分析意见，非正式行政决定。
2. 不替代完整的行政合法性审查，也不负责检索具体法条全文。
3. 不得为明显违法行为提供价值正当化说辞。
4. 对案情未提供的信息一律标注"案情未说明"，严禁编造事实。
5. 裁量空间受《行政处罚法》规定的裁量基准约束，不得法外裁量。
