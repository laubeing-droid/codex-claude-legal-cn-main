# 商标注册助手

## 一、功能概述

为商标申请人及代理人提供全流程辅助，从商标构思到注册完成各环节提供操作性建议。

(一) 适用对象
1. 创业者和小微企业，自行申请商标注册
2. 企业法务人员管理商标组合
3. 商标代理人提高审查效率

(二) 覆盖流程
商标定名 → 类别选择 → 可注册性初筛 → 申请文书 → 审查意见答复 → 异议应对

## 二、商标类别规划

(一) 尼斯分类体系
中国采用尼斯分类第12版，共有45个类别（第1-34类为商品，第35-45类为服务）。

(二) 选类原则
1. 核心类别：当前经营的商品或服务所属类别，必须注册
2. 关联类别：上下游、配套产品/服务所属类别，建议注册
3. 防御类别：不经营但容易被蹭名的类别，可酌情考虑
4. 互联网相关企业特别关注第35类（广告、商业管理）、第42类（科技服务、软件开发）

(三) 商品/服务项目选择
1. 每个类别可选10个标准项目（超出部分另计官费）
2. 优先选择《类似商品和服务区分表》中的标准名称
3. 避免自创非标准商品描述，容易被补正
4. 核心商品/服务优先，兼顾未来发展需要

## 三、可注册性初筛

(一) 绝对理由审查（商标法第10、11条）
1. 是否使用了国家名称、国旗等禁用标志
2. 是否缺乏显著特征（仅描述商品功能、用途、数量等）
3. 是否为商品的通用名称或图形
4. 是否具有欺骗性

(二) 相对理由审查（商标法第28条标准）
1. 与在先商标是否构成近似（字形、读音、含义综合判断）
2. 指定商品/服务是否类似
3. 与他人驰名商标是否存在混淆可能

(三) 显著性评估
1. 臆造词汇：显著性最强
2. 任意词汇：与商品无关的现有词
3. 暗示性词汇：提示商品特征但不直接描述
4. 描述性词汇：需经使用获得第二含义
5. 通用名称：不具备商标资格

## 四、申请材料整理

(一) 必备文件
1. 商标注册申请书（填写申请人信息、商标图样、商品/服务项目）
2. 商标图样（JPG格式，清晰可辨）
3. 申请人身份证明（营业执照/身份证）
4. 代理委托书（如委托代理机构）

(二) 特殊类型额外材料
1. 集体商标/证明商标：管理规则、使用条件说明
2. 声音商标：音频文件及文字说明
3. 颜色组合商标：颜色编号及使用方式说明

## 五、审查意见答复

(一) 常见驳回理由
1. 与在先商标近似（最多见）
2. 缺乏显著特征
3. 含有不得作为商标使用的文字
4. 商品/服务项目不规范需补正

(二) 答复策略
1. 近似驳回：提交不近似论证（读音、字形、含义、整体视觉效果）
2. 显著性驳回：提交使用证据证明已获得第二含义
3. 补正通知：按要求修改申请书信息

## 六、流程节点提示

(一) 关键时间线
1. 形式审查：约1个月
2. 实质审查：约5-8个月（可申请加快）
3. 初审公告：3个月
4. 注册公告与发证：约1-2个月

(二) 续展与维护
1. 注册商标有效期10年
2. 到期前12个月内可申请续展
3. 持续使用3年可对抗"撤三"申请
4. 注意保留商标使用证据

## 七、注意事项

1. 本工具提供的是辅助判断，不构成法律意见
2. 商标查询结果以商标局官方数据库为准
3. 涉及跨境商标注册需参考马德里体系规则
4. 重要商标建议委托专业代理机构办理
