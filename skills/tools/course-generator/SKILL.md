# Course Generator

## 一、功能概述

课程内容全生命周期管理，三种模式覆盖生成、保存与定制场景。

(一) 生成模式——转录稿或文献整理为结构化课程
(二) 归档模式——成品课程按规范存入知识库
(三) 提取模式——根据客户需求从素材中重组成定制方案

核心原则：
- 忠实原文，保留核心观点、案例、数据，不添加文档外信息
- 叙述性写作，以段落论述为主，流程性内容可用列表辅助
- 独立正文去除转录痕迹，不出现"现场演示""主讲人提到"等来源表述
- 专有名称保真，Skill名/工具名/API名保持原始语言不翻译
- 图片资产完整保留但正文插图克制，仅插入核心图与必要辅助图

## 二、前置配置

首次使用时复制 `config/paths.example.yaml` 为 `config/paths.yaml` 并配置路径：
- `knowledge_base`——知识库根目录
- `archive_root`——课程归档路径
- `curriculum_file`——课程主题体系文件
- `training_root`——培训材料根目录

用户词典（可选）：复制 `config/user_dictionary.example.yaml` 为 `config/user_dictionary.yaml`，在 `terms` 中添加正确术语。词典只维护正确写法，AI负责基于上下文识别并修正近似误转写。

## 三、生成模式流程

```
读取文献 → 词典校正 → 建立图片资产表 → 识别内容特征 → 生成大纲 → 生成总览 → 生成专题 → 归档
```

(一) 文献读取
使用Glob一次性读取目标目录下所有 `.md`/`.txt` 文件。

(二) 术语校正
根据用户词典中的术语列表，在转录内容中查找高置信的近似误转写并修正。

(三) 图片处理
- 按原文顺序建立图片资产表（IMG-001起编号）
- 每张图片标注价值（核心/辅助/低价值/跳过）和正文处理（插入/仅资产表保留/跳过）
- 核心图（框架、界面、流程、证据）优先插入；辅助图在不造成堆叠时插入
- 连续插图不超过2张，确有必要最多3张

(四) 大纲生成
一次性分析所有文献，基于素材特征自动生成课程大纲。详见 `references/outline_prompt.md`。

(五) 总览与专题文档生成
- 总览：`00 [课程名称] - 总览.md`，详见 `references/overview_prompt.md`
- 专题：按章节逐一生成，从11个可选模块中灵活组合（引言、核心概念、理论框架、实践案例、应用场景、最佳实践、对比分析、未来展望、本章小结、延伸阅读等）

排版要求：三级标题用 `### 1、` 格式，段落160-240字，Q&A融入对应章节不单独成章。

## 四、归档模式与提取模式

(一) 归档模式
读取课程文件→按命名规范确定路径→复制归档→更新知识库索引。

(二) 提取模式
解析客户需求（受众/时长/方向）→匹配课程讲次→定位素材→提取重组→输出方案。

需求维度：受众类型、AI基础水平、培训时长、重点方向（认知/工具/案例/组织等）。
