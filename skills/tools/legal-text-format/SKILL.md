# 法律文本格式化

将来源各异的法律文本转换为统一规范格式，保证原始信息完整的同时清除杂乱。

## 一、处理对象

### (一) 法律条文

包括法律法规原文、司法解释、部门规章等。格式化后按编章节条层级呈现。

### (二) 法律案例

包括裁判文书、典型案例、法院公告等。保留当事人信息脱敏后的案例事实与裁判要旨。

### (三) 混合文本

含法律与非法律内容的复合文本（如公众号文章、培训讲稿），提取法律核心部分并标注来源。

## 二、格式化规则

### (一) 公共规则

- 去除推广信息：广告、引流话术、二维码、外链
- 统一标点：中文上下文使用全角标点
- 统一缩进：段落首行缩进两字符（法律条文层级除外）
- 修正换行：合并不当断行，保留有意分段

### (二) 条文专用规则

- 层级标识：编→章→节→条→款→项
- 条号格式："第一条""第二条"
- 保留原条号，不自行编序

### (三) 案例专用规则

- 当事人信息替换为通用指代
- 保留案件编号与审理法院
- 保留"经审理查明""本院认为"等裁判文书结构标记

## 三、处理流程

1. 自动识别文本类型（条文/案例/混合）
2. 按类型应用对应规则清洗
3. 内容完整性校验：对比格式化前后的关键信息量
4. 输出至归档目录

## 四、归档与溯源

输出按时间戳组织：
```
archive/{YYYYMMDD}_{主题}/
├── {日期}_{主题}_raw.md # 原始文本
└── {日期}_{主题}_formatted.md # 格式化文本
```

保留原始文件确保可溯源比对。

## 五、来源协作

支持接收来自抓取类技能（如 wechat-article-fetch）的文本作为输入，由本技能专注完成格式化清洗。

## 六、使用方式

```
/legal-text-format [粘贴法律文本]
```

或：
```
/legal-text-format @文章原文.md
```

## 七、参考文件

- `references/examples.md`：格式化前后对比示例
- `scripts/`：Python 辅助脚本
