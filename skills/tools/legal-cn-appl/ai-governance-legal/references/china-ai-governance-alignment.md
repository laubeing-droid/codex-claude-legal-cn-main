# 中国数据合规与人工智能监管制度对照

> 中国数据治理体系以网络安全法、数据安全法、个人信息保护法及生成式AI服务管理暂行办法构成主干框架，与美欧监管范式存在结构性差异。

## 一、核心概念映射

（一）个人数据保护领域

| 域外惯用术语 | 中国法对应概念 | 映射精度 | 主要依据 |
| :--- | :--- | :--- | :--- |
| personal data / PII | 个人信息 | 实质等同 | 个保法第4条 |
| sensitive personal data | 敏感个人信息 | 实质等同 | 个保法第28条 |
| data controller | 个人信息处理者 | 实质等同 | 个保法第5条 |
| data processor | 受托处理者 | 实质等同 | 个保法第21条 |

（二）数据跨境与本地化

| 域外概念 | 中国制度定位 | 映射特征 | 核心规范 |
| :--- | :--- | :--- | :--- |
| cross-border data transfer | 数据出境 | 功能对应 | 个保法第38条、数安法第31条 |
| data localization | 数据本地化存储 | 实质等同 | 网安法第37条 |

跨境传输采用三路径并行机制：国家网信部门安全评估、个人信息出境标准合同备案、以及个人信息保护认证。关键信息基础设施运营者须在境内保存数据，确需出境则必须通过安全评估。

（三）中国独有制度安排

| 独特制度 | 制度要点 |
| :--- | :--- |
| 重要数据与核心数据分级 | 数安法第21条确立以国家安全为基准的分级分类体系 |
| 数据出境安全评估 | 处理超百万人信息或累计出境达法定门槛须经网信办审查 |
| 算法备案 | 生成式AI服务上线前须完成安全评估与算法备案，属行政准入前置程序 |

## 二、跨境实务要点

（一）数据出境阈值判定

安全评估的触发门槛包含三类情形：处理百万级以上个人信息的主体、累计向境外提供十万条个人信息或一万条敏感信息的场景、以及关键信息基础设施运营者。其他情形可选择标准合同或认证路径。

（二）算法监管属性

算法备案构成AI服务市场准入的法定前置条件，性质上不同于域外自愿性伦理框架。生成式AI的内容标识义务为强制性要求，非建议性操作。

## 三、域外概念阻断清单

涉及中国AI治理事务时须注意：

- 不得以行业自律模式评估中国AI合规，中国实行行政准入制
- 算法备案为法定前置，不得降格为建议性安排
- 生成式AI内容标识属法定义务，非最佳实践指南

## 四、港区法域衔接

| 域外用语 | 香港表述 | 内地表述 | 差异风险 |
| :--- | :--- | :--- | :--- |
| AI regulation | AI规管 | 算法备案与安全评估 | 香港无专项AI立法 |
| personal data | 个人资料 | 个人信息 | 香港私隐条例独立体系 |
| data localization | 资料本地化 | 数据本地化存储 | 制度要求有别 |
