# 合同审查操作清单（AI可执行）

## 一、合同识别阶段

### (一) 基本定性

1. 合同类别归属：有名合同、无名合同或混合型。
2. 法律性质判断：双务或单务、有偿或无偿、诺成或实践。
3. 审查站位确定：甲方视角、乙方视角或中立立场，直接影响修改建议方向。

## 二、效力审查阶段

### (一) 成立要件

1. 要约与承诺是否均已完备。
2. 合同外在形式是否满足法定要求（书面、口头或电子）。
3. 签约当事人是否具有相应民事行为能力。

### (二) 效力状态筛查

1. 是否抵触法律强制性规定 → 无效。
2. 是否损害公共秩序与善良风俗 → 无效。
3. 是否存在通谋虚伪表示损害他人利益 → 无效。
4. 是否存在重大误解 → 可撤销。
5. 是否存在欺诈性表示 → 可撤销。
6. 是否存在受胁迫签订 → 可撤销。
7. 是否显失公平 → 可撤销。
8. 是否存在无权代理 → 效力待定。
9. 是否存在无权处分 → 效力待定。

## 三、格式条款专项检查

### (一) 提示说明义务

1. 是否以醒目方式提请对方关注重大利害关系条款。
2. 是否根据对方请求对格式条款予以解释说明。
3. 是否存在免除已方责任或加重对方负担的约定 → 无效。
4. 是否存在排除对方核心权利的条款 → 无效。
5. 是否含有"最终解释权归本店"类表述 → 无效。
6. 是否借技术手段强制对方接受交易条件 → 违法。
7. 格式与非格式条款冲突时是否以非格式条款为准。
8. 格式条款存在多重解释时是否采取对提供方不利的解释。

## 四、核心条款审查

### (一) 法定必备要素

1. 合同标的：数量、质量标准、规格型号是否清晰。
2. 价款报酬：金额币种、计价方式、支付时点是否明确。
3. 履行期限：起止日期及阶段性节点是否确定。
4. 履约地点与方式是否具体可操作。
5. 违约条款是否可量化执行而非笼统表述。
6. 争议解决方式是否明确，仲裁机构名称须精确。

### (二) 违约责任审查

1. 违约金是否超出实际损失三成以上，超出部分可请求司法调减。
2. 定金金额是否超过合同总额的五分之一。
3. 免责条款是否排除人身伤害责任 → 无效。
4. 免责条款是否排除故意或重大过失责任 → 无效。

### (三) 其他关键条款

1. 管辖法院或仲裁地是否对己方有利。
2. 是否存在单方任意解约权，建议加以限制。
3. 保密条款覆盖范围是否适当。
4. 知识产权归属尤其在委托开发或合作开发场景须明确。
5. 不可抗力条款建议纳入政府行为等情形。

## 五、消费者合同专项

### (一) 重点检查项

1. 自动续费环节是否在到期前以显著方式提示。
2. 搭售或组合销售是否逐项醒目告知。
3. 是否利用技术手段实施差异化定价。
4. 预付式消费是否约定退款机制。
5. 退换修期限与方式是否符合法律规定。
6. 是否存在限制消费者投诉或诉讼权利的条款 → 无效。

## 六、数据条款专项

1. 是否涉及个人信息处理，若涉及须独立授权并链接隐私政策。
2. 是否涉及敏感个人信息，需单独同意并说明必要性。
3. 是否涉及数据出境，需安全评估、标准合同或认证择一完成。
4. 受托数据处理方的义务边界是否清晰。

## 七、签章与生效条款专项

1. 生效条件是否写明"签字并加盖公章或合同专用章"。
2. 签约方信息是否包含法定代表人或授权代表。
3. 多页合同是否约定加盖骑缝章以防换页。
4. 对外担保或重大资产处置是否核查前置的股东会或董事会决议，缺失则担保合同可能无效。
5. 电子签约场景是否援引可靠电子签名要件标准。

## 八、风险评级与输出

1. 逐条标注风险等级：高、中、低。
2. 每条风险附法律依据及修改建议，含推荐方案与最低可接受方案。
3. 输出总体风险评级及谈判策略建议。
