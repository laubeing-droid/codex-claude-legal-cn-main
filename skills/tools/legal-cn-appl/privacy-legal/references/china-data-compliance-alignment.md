# 中国数据合规与AI监管制度对照

> 中国数据治理体系以网安法、数安法、个保法及生成式AI服务管理暂行办法构成主干框架，与域外监管范式存在结构性差异。

## 一、核心概念映射

（一）个人数据保护

| 域外惯用术语 | 中国法对应概念 | 映射精度 | 主要依据 |
| :--- | :--- | :--- | :--- |
| personal data / PII | 个人信息 | 实质等同 | 个保法第4条 |
| sensitive personal data | 敏感个人信息 | 实质等同 | 个保法第28条 |
| data controller | 个人信息处理者 | 实质等同 | 个保法第5条 |
| data processor | 受托处理者 | 实质等同 | 个保法第21条 |

（二）数据跨境与安全

| 域外概念 | 中国制度定位 | 映射特征 | 核心规范 |
| :--- | :--- | :--- | :--- |
| cross-border data transfer | 数据出境 | 功能对应 | 个保法第38条、数安法第31条 |
| data localization | 数据本地化存储 | 实质等同 | 网安法第37条 |
| important / core data | 重要数据与核心数据分级 | 中国特色 | 数安法第21条 |

（三）中国特色制度

数据出境实行三路径并行：网信办安全评估、个人信息标准合同备案、以及个人信息保护认证。算法备案构成生成式AI服务市场准入的法定前置条件。

## 二、数据出境决策节点

判断个人信息出境是否需要通过安全评估，可按以下层次对照：

- 处理超百万人个人信息的主体：必须安全评估
- 累计向境外提供十万条个人信息或一万条敏感信息：必须安全评估
- 属于关键信息基础设施运营者：必须安全评估
- 其他情形：可选标准合同或认证路径

## 三、域外概念阻断清单

- 不得引入域外合法利益作为独立的处理合法性基础
- 中国个保法第13条以同意加法定豁免构建合法性基础体系
- 数据治理不得套用行业自律评估框架

## 四、港区法域衔接

| 域外用语 | 香港表述 | 内地表述 | 差异风险 |
| :--- | :--- | :--- | :--- |
| personal data | 个人资料 | 个人信息 | 香港私隐条例独立体系 |
| data transfer | 资料转移 | 数据出境 | 跨境传输规则不同 |
| discovery | 文件透露 | 证据交换 | 本质差异 |
