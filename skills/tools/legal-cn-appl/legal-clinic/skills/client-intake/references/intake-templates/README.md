# 客户接案模板说明

## 一、模板结构

### (一) 基本信息收集

客户姓名、联系方式、身份证件类型及号码、常住地址。

### (二) 案件类型识别

劳动争议、婚姻家庭、合同纠纷、侵权赔偿、刑事辩护、行政争议、知产保护、公司治理等分类标签。

### (三) 案情简述

当事人自述的争议事由、关键时间节点、涉及金额及已采取的救济措施。

## 二、模板使用规则

### (一) 冲突检索

接案前须对对方当事人进行利益冲突检索，确认不存在代理冲突后方可进入后续流程。

### (二) 敏感信息脱敏

采集身份证号、住址、银行账号等个人敏感信息时须即时完成脱敏处理，仅保留案件分析所需的最小必要信息。

### (三) 电子签名授权

委托代理合同须经由可靠电子签名或线下纸质签署完成授权确认。

## 三、模板文件清单

本目录存放按案件类型分类的接案登记表模板，每种类型含必填字段与可选字段定义。
