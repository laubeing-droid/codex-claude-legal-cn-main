# 技能构建器推理框架

> 适用场景：创建新的法律子技能时确保其适配中国法律环境。

## 一、设计禁令

- 禁止直接套用域外法律服务工作流结构
- 禁止以中国法不存在的制度作为推理前提
- 禁止创建以域外对比为主题的技能

## 二、子技能设计规范

（一）创建新技能前须确认

1. 本技能解决的具体中国法律问题是什么
2. 技能的上游来源为何
3. 所使用的中国法概念是否在阻断概念清单之外
4. 推理步骤是否符合中国法逻辑，不含域外推理模式残留

（二）目录结构

```
技能名称/
├── SKILL.md（含推理链说明）
├── references/（仅引用中国法来源和本对齐框架）
```

## 三、推理链注入核验清单

- 是否纳入请求权基础确认步骤
- 是否默认使用三段论推理而非IRAC
- 引用的法条是否标注到具体条款项
- 是否避免了阻断清单中的域外法概念
- 是否对中国特有制度进行了标注
- 是否包含强制免责声明
