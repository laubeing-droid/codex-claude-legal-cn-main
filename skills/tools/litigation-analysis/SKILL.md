# 诉讼文档分析

面向主办律师的诉讼材料智能解析，支持三种主场景和递进输出体系。

## 一、处理场景

### (一) 起诉材料分析

针对案件初期文书与证据，进行快速策略评估：

- 诉求合理性检视、事实脉络梳理、证据链完整性评估
- 风险点预判与追加证据建议

### (二) 判决书解析

这是本技能的核心场景。对一审或二审判决书展开结构化深度摄取，按依赖关系递进生成三份产物：

1. 内部版：面向承办律师，包含完整事实链条、法院认定逻辑、法律适用论证
2. 研究版：基于内部发现的法律议题，提炼研究课题清单
3. 客户版：去术语化呈现，便于非法律背景当事人理解

核心目标：掌握裁判逻辑全貌，为上诉或再审决策提供依据。

### (三) 庭审笔录复盘

对庭审结束后的文字稿生成结构化分析：

- 法庭归纳的争议焦点
- 双方证据与质证态势
- 法官提问透露的审理倾向
- 时限安排及待完成事项
- 后续诉讼策略调整建议

## 二、分析维度

针对判决书，统一从以下维度深入：

- 当事人信息及代理情况
- 案件来龙去脉与审理层级
- 原告主张、被告抗辩
- 证据采信与事实认定
- 争议焦点逐项法院说理
- 判决主文、诉讼费分配、上诉权利告知
- 裁判要旨提炼与实务启示

## 三、输出结构

### (一) 判决书输出序列

内部版先行，研究版和客户版在内部版完成后依序产出：

```
[案号]/
├── [案号] 深度分析内部版.md
├── [案号] 研究课题清单.md
└── [案号] 案件概览客户版.md
```

### (二) 内部版核心模块

- 要旨速览：篇幅控制在三分钟阅读量
- 事实与证据：完整认定链条
- 争议焦点与法院认定：逐项对照
- 判决详解：主文、费用、上诉权
- 法律分析与策略：上诉/再审可行性
- 裁判要点与实务启示

## 四、使用方式

基于文件引用：
```
/litigation-analysis @判决书路径.md
```

提供辅助文件（起诉状、答辩状等）时一并提及。

可直接粘贴内容：
```
/litigation-analysis [粘贴判决书全文]
```

## 五、领域扩展

现有专用分析维度覆盖知识产权与不正当竞争案件，含专利权、商标权、著作权、商业秘密等细分方向。劳动法、公司法、合同法等领域待后续补充。

## 六、质量要求

- 事实认定必须回扣判决书原文段落
- 法律分析需区分"法院明确认定"与"推测性解读"
- 信息不足处标注"未提及/待补充"
- 策略建议须可执行，不写泛泛的"建议谨慎处理"
