# 命令元规范

**版本**: v3.0
**更新日期**: 2026-06-05

## 一、适用范围

本文件仅约束 `.claude/commands/` 内的命令配置。其他目录（skills、rules、agents）各自另有约定。

## 二、命名约定

### （一）通用格式

采用全小写加短横线（kebab-case）：

```
动作-对象.md       例：new-case.md
工具名.md           例：deepresearch.md
set-配置项.md       例：set-model.md
```

### （二）禁止写法

严禁下划线、驼峰、大写字母出现于命令文件名中。

## 三、前置元数据

每个命令文件必须以 YAML 头起首：

```yaml
---
name: 命令标识（与文件名一致，不含.md）
description: 一句话说明用途与触发场景
---
```

name 字段要求：纯小写短横线，直接复现文件名。description 要求：陈述语气，点明解决什么问题。

## 四、版本号制度

采用三位语义化编号：

- 主号：不兼容的重大变更
- 次号：向下兼容的功能追加
- 修订号：缺陷修补

## 五、变更记录

文件末尾必须有版本表格，倒序排列，每条控制在二十字以内，一律用中文。关键词限定为"新增/优化/修复/删除/重构"。

## 六、校验清单

1. 文件名 kebab-case 合规
2. YAML 头包含 name 与 description
3. name 与文件名吻合
4. 变更历史表格格式正确
5. 版本号语义化
