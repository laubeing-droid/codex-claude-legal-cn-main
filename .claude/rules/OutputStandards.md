# 智能体输出标准

**版本**: v3.0
**更新日期**: 2026-06-05

## 一、总体原则

- 仅生成 Markdown 文件，不输出 JSON 等其他格式
- 文件必经日期前缀，格式：`YYMMDD 描述.md`
- 持续维护类文档免日期前缀（如工时记录、yaml 期限文件）

## 二、文件分类

### （一）一次性产出

每次生成均带日期前缀，保留历史版本：

| 智能体 | 命名模板 |
|--------|---------|
| DocAnalyzer | `YYMMDD [文档名]解析结果.md` |
| EvidenceAnalyzer | `YYMMDD 证据分析报告.md` |
| IssueIdentifier | `YYMMDD 争议焦点分析.md` |
| Researcher | `YYMMDD 法律研究报告.md` |
| Strategist | `YYMMDD 应诉策略方案.md` |
| Writer | `YYMMDD [文书类型].md` |
| Summarizer | `YYMMDD [摘要类型]摘要.md` |
| Reporter | `YYMMDD [报告类型]报告.md` |

### （二）持续维护

`[案号]工时记录.md` 与 `[案号].yaml` 不附加日期，单文件滚动更新。

## 三、正文结构

```
# 主标题
## 一、核心要点
## 二、详细分析
## 三、结论与建议
```

标题用 `#` 至 `####` 四级。列表用 `-`，粗体标识重点，引用用 `>`。

## 四、各智能体输出模板速览

### （一）DocAnalyzer
关键信息提取 + 结构化数据 + 分析总结

### （二）EvidenceAnalyzer
证据概述 → 三性（真实/合法/关联）质证 → 综合结论 → 补充建议

### （三）IssueIdentifier
主要争议 → 次要争议 → 法律关系 → 适用法条 → 优先级矩阵

### （四）Researcher
法条解读 → 典型案例 → 适用分析 → 证据收集建议 → 研究结论

### （五）Strategist
SWOT 四象限 → 风险评估 → 策略方案（进攻/防守/折中） → 资源建议

### （六）Writer
当事人信息 → 诉讼请求 → 事实理由 → 证据目录 → 此致 → 附件

### （七）Summarizer
核心要点 → 详细内容 → 风险提示 → 行动建议

### （八）Reporter
案件概况 → 工作成果 → 关键发现 → 风险问题 → 后续计划

### （九）Scheduler
案件概况 → 时间线 → 工时统计 → 期限提醒 → 费用预算

## 五、质量基准

内容须准确、完整、逻辑自洽，术语须专业。格式须统用 Markdown，结构清晰可读。

校验项：md 格式、日期前缀、输出目录、章节完备、无错字。
