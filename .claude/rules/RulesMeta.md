# 规则元规范

**版本**: v3.0
**更新日期**: 2026-06-05

## 一、适用范围

仅约束 `.claude/rules/` 内的配置文件。agents、skills 等其他目录各循其规。

## 二、文件命名

统一使用 PascalCase：首字母大写，单词直接拼接，不加连接符。

| 类型 | 命名模式 | 代表文件 |
|------|---------|---------|
| 配置类 | `名词.md` | `AgentMapping.md` |
| 规范类 | `XxxRules.md` 或 `XxxStandards.md` | `TimeRules.md` |
| 工作流类 | `名词.md` | `Workflow.md` |

## 三、标准文档骨架

### （一）标题区

```markdown
# 文档名

**版本**: 1.0
**更新日期**: YYYY-MM-DD
**说明**: 可选概述
```

### （二）正文章节

采用 `## 一、`、`### （一）` 层级，可用适量 emoji 图标辅助辨识。

### （三）尾部

必须附版本变更表格，倒序排列，以 `---` 分隔线收尾。

## 四、版本制度

继续沿用语义化三位编号：

- 主号 — 架构推翻
- 次号 — 兼容新增
- 修订号 — 修复缺陷

## 五、变更记录约定

一律中文，倒时序，每条不超过二十字。关键词限于"新增/优化/修复/删除/重构"。

## 六、章节 emoji 对照

| emoji | 适用场景 |
|-------|---------|
| 🎯 | 核心原则 |
| 📋 | 规范说明 |
| 📁 | 目录结构 |
| 🔤 | 命名规则 |
| 🔄 | 变更历史 |
| 🚨 | 注意警告 |
| ✅ | 检查清单 |
| ❌ | 反例 |

## 七、文件校验清单

1. 文件名 PascalCase 合规
2. 版本与更新日期已填
3. 变更历史表格完整
4. 无空章无冗余
