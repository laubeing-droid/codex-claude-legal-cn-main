# 法律深度研究

**版本**: v3.0
**更新日期**: 2026-06-05

## 一、功能

将输入材料自动拆分为若干研究课题，每个课题启动独立子智能体并发检索，最后整合为统一研究总览。输入形式不限——聊天记录、方案文本、案例描述、法条片段皆可。

## 二、核心特点

### （一）并发架构
每个课题一个子智能体，互不等待，并行运转。

### （二）聚焦检索
单个子智能体执行 4–6 轮搜索，使用内置 WebSearch / WebFetch，无需额外配置。课题间确保检索方向不重叠。

### （三）标准化输出
产物落入 `03 - 法律研究` 目录，文件以 `YYMMDD 课题名.md` 命名。另有一份总览文档整合全部发现与行动建议。

## 三、使用方式

- **基于文件**：`/deepresearch @材料路径.md`
- **直接粘贴**：`/deepresearch` 后粘贴材料内容
- **指定课题**：`/deepresearch` 后提供案件名与研究课题列表

## 四、执行三阶段

### （一）分析准备（主智能体）
读材料 → 提课题 → 去重拆分 → 建目录。拆分要点：方向各异、检索词不交叠、每课题只盯一个问题。

### （二）并行检索（子智能体）
各子智能体自主选择 WebSearch 或 WebFetch，围绕单一课题深入挖掘。输出聚焦文档，结论可直接落地，长度以解决问题为限。

### （三）汇总整合（主智能体）
产出 `000.研究总览.md`，收束核心发现，串联文档间链接，附策略建议与行动排期。

## 五、输出结构

```
[案号]/03 - 法律研究/
├── 000.研究总览.md
├── YYMMDD 课题一.md
└── YYMMDD 课题二.md ...
```

## 六、链接规范

全部来源链接嵌入正文对应位置，按类型标注（⚖️ 法条、📚 判例、🏛️ 机构、🔗 通用资源）。文末不另设参考文献章。

## 七、严禁事项

- 不建二级子目录、不生独立执行总结文件
- 不堆砌要点列表、不在文末集中罗列引用
- 不添加进度追踪冗余段落

## 八、课题编号约定

- `00` — 研究总览
- `01-09` — 核心研究
- `10-19` — 重要研究
- `20+` — 延伸研究
